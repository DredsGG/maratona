Como usar

Não tem nada para configurar: abra um episódio na Crunchyroll e assista.

  • Abertura e recapitulação: assim que o botão Pular introdução da Crunchyroll aparece, a Maratona aperta.
  • Créditos: aperta Pular créditos. Se em 5 segundos o episódio não trocar, aperta o Próximo episódio do player. Cena pós-créditos não é cortada.
  • Aviso no player: mostra o que foi pulado, com Desfazer. Antes de trocar de episódio aparece a contagem com Cancelar.
  • Ícone da extensão: liga e desliga cada parte, troca o idioma e mostra o tempo economizado. No rodapé: Procurar atualização, Relatar bug e ? (tutorial).

How to use

Nothing to set up: open an episode on Crunchyroll and watch.

  • Intro and recap: as soon as Crunchyroll's Skip Intro button shows up, Maratona presses it.
  • Credits: presses Skip Credits. If the episode hasn't changed after 5 seconds, it presses the player's Next episode. Post-credit scenes aren't cut.
  • Notice on the player: shows what was skipped, with Undo. Before changing episodes there's a countdown with Cancel.
  • Extension icon: turns each part on or off, changes the language and shows the time saved. Footer: Check for updates, Report a bug and ? (tutorial).

Cómo usar

No hay nada que configurar: abre un episodio en Crunchyroll y mira.

  • Intro y resumen: en cuanto aparece el botón Saltar intro de Crunchyroll, Maratona lo pulsa.
  • Créditos: pulsa Saltar créditos. Si en 5 segundos el episodio no cambia, pulsa el Siguiente episodio del reproductor. Las escenas poscréditos no se cortan.
  • Aviso en el reproductor: muestra qué se saltó, con Deshacer. Antes de cambiar de episodio aparece la cuenta atrás con Cancelar.
  • Ícono de la extensión: activa o desactiva cada parte, cambia el idioma y muestra el tiempo ahorrado. Pie: Buscar actualización, Reportar error y ? (tutorial).

Instalar

Chrome, Edge, Brave e Opera GX

  1. Baixe o maratona-vX.Y.Z.zip do Release no GitHub e extraia numa pasta fixa (ela vai ficar lá).
  2. Abra chrome://extensions (ou edge://extensions, brave://extensions, opera://extensions).
  3. Ligue o Modo do desenvolvedor, clique em Carregar sem compactação e escolha a pasta.

Opera GX: se a extensão sumir depois de fechar o navegador, carregue de novo (problema conhecido do Opera).

Firefox 140+

  1. Baixe o maratona-vX.Y.Z.xpi do Release e confirme a instalação (ou about:addons → engrenagem → Instalar extensão de arquivo).
  2. Ele se atualiza sozinho.

Install

Chrome, Edge, Brave and Opera GX

  1. Download maratona-vX.Y.Z.zip from the GitHub Release and extract it to a fixed folder (it stays there).
  2. Open chrome://extensions (or edge://extensions, brave://extensions, opera://extensions).
  3. Turn on Developer mode, click Load unpacked and pick the folder.

Opera GX: if the extension disappears after closing the browser, load it again (known Opera issue).

Firefox 140+

  1. Download maratona-vX.Y.Z.xpi from the Release and confirm the install (or about:addons → gear → Install Add-on From File).
  2. It updates itself.

Atualizar

A Maratona procura versão nova sozinha (a cada 30 min e quando você volta para a aba da Crunchyroll). Quando acha, aparece um aviso no meio da página, na hora. O X só adia por 1 hora. Se a versão for urgente (conserto de um problema grave), o aviso não tem X e a Maratona fica pausada até você atualizar. O botão Atualizar baixa o zip novo para Downloads: extraia por cima da mesma pasta. A extensão percebe sozinha em até 1 minuto e se recarrega, sem precisar mexer em chrome://extensions. No Firefox, confirme a instalação do .xpi (ou espere: ele atualiza sozinho).

Update

Maratona checks for new versions by itself (every 30 min and whenever you come back to the Crunchyroll tab). When it finds one, a notice shows up in the middle of the page right away. The X only postpones it for 1 hour. If the version is urgent (a fix for a serious problem), the notice has no X and Maratona stays paused until you update. The Update button downloads the new zip to Downloads: extract it over the same folder. The extension notices within a minute and reloads itself, no need to touch chrome://extensions. On Firefox, confirm the .xpi install (or wait: it updates itself).

Actualizar

Maratona busca versiones nuevas sola (cada 30 min y cuando vuelves a la pestaña de Crunchyroll). Cuando encuentra una, aparece un aviso en el medio de la página al instante. La X solo lo pospone 1 hora. Si la versión es urgente (arreglo de un problema grave), el aviso no tiene X y Maratona queda en pausa hasta que actualices. El botón Actualizar descarga el zip nuevo a Descargas: extráelo sobre la misma carpeta. La extensión lo nota sola en hasta 1 minuto y se recarga, sin tocar chrome://extensions. En Firefox, confirma la instalación del .xpi (o espera: se actualiza solo).

Não está pulando?

  • Confira se o ícone não está com OFF (desligada no popup).
  • Firefox: em about:addons → Maratona → Permissões, deixe ligado o acesso a www.crunchyroll.com.
  • Recarregue a página do episódio (F5). Se continuar, use Relatar bug no popup.

Not skipping?

  • Check the icon doesn't show OFF (turned off in the popup).
  • Firefox: in about:addons → Maratona → Permissions, keep access to www.crunchyroll.com on.
  • Reload the episode page (F5). If it keeps happening, use Report a bug in the popup.

¿No salta?

  • Revisa que el ícono no muestre OFF (desactivada en el popup).
  • Firefox: en about:addons → Maratona → Permisos, deja activado el acceso a www.crunchyroll.com.
  • Recarga la página del episodio (F5). Si sigue, usa Reportar error en el popup.
